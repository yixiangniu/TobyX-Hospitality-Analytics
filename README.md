# TobyX Hospitality Analytics Portfolio

A collection of four hospitality analytics projects completed during my
TobyX Data Analyst internship, using simulated business datasets.

The projects cover customer value, marketing effectiveness, pricing and
demand, and operational performance.

## Projects

| Project | Focus | Folder |
| --- | --- | --- |
| 1. Customer & Revenue Analysis | Customer value, booking preferences, and data quality exploration | [Project 1](./Project%201/) |
| 2. Marketing Effectiveness | Campaign performance, customer bookings, and revenue patterns | [Project 2](./Project%202/) |
| 3. Pricing & Demand Strategy | Data preparation and analysis of pricing and demand patterns | [Project 3](./Project%203/) |
| 4. Operational Performance | SLA performance, issue analysis, and operational reporting | [Project 4](./Project%204/) |

## Tools

- Python and pandas for data exploration, preparation, and analysis
- Jupyter Notebook for documenting analytical work
- Power BI and DAX for dashboards and business reporting
- Excel for source datasets and analysis outputs

## Repository Contents

Each project folder contains its available datasets, analysis notebooks,
Power BI files, and supporting documents.

To explore the work:
1. Open the Jupyter notebooks to review the analysis and saved outputs.
2. Download the `.pbix` files and open them in Power BI Desktop.
3. Read the PDF presentations where available for findings and recommendations.

## Data Context

All four projects use simulated datasets for internship training.
Findings describe these datasets and do not represent actual client
performance or measured business impact.
